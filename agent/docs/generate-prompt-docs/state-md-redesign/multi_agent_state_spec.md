## 1. Executive Summary

Replace the single-file `agent/state.md` overwrite system with a **Hub + Spokes** architecture:

- **Hub** (`agent/state.md`): Read-only global index. All agents load it. Shows who's active, what they're doing, and where to find details. Auto-generated by the main process.
- **Spokes** (`agent/state/{sessionId}.md`): One per agent session. Each agent writes ONLY its own spoke. Contains full history (latest 3 cycles).
- **Template** (`agent/state/_template.md`): Static format reference. Loaded into agent context.

**Core principle:** *Each agent owns exactly one file. No two agents ever write to the same file.*

## 3. Session ID Scheme

```
Format:    {agentType}-{terminalIdPrefix}-{entropy}
Example:   opencode-a3f9b2-7843

- agentType:        'opencode' | 'claude' | 'codex' | 'gemini'
- terminalIdPrefix: terminalId.slice(0, 6)  (e.g., 'a3f9b2')
- entropy:          Date.now().toString(36).slice(-4)  (4-char base36)

Passed to agent process via environment variables:
  DESKFLOW_SESSION_ID={sessionId}
  DESKFLOW_AGENT_TYPE={agentType}
  DESKFLOW_TERMINAL_ID={terminalId}
  DESKFLOW_PROJECT_PATH={projectPath}
```

**Why this scheme:**
- Human-readable: you can tell agent type and terminal at a glance
- Unique enough: 4-char base36 entropy = 1.6M combinations, plus timestamp
- File-safe: no slashes, spaces, or special characters
- Sortable: agent type groups files together in directory listings

## 4. Data Model

### 4.1 Agent Cycle State (one entry per cycle)

```typescript
interface AgentCycleState {
  cycleNumber: number;           // Monotonic counter, increments each cycle
  timestamp: string;             // ISO 8601 with timezone, e.g. "2026-07-25T18:58:00+07:00"
  role: string;                  // What the agent is doing this cycle
  status: 'working' | 'idle' | 'error' | 'completed';
  inFlight: string[];            // Active tasks (array, one per line)
  completed: string[];           // Tasks finished this cycle
  nextAction: string;            // What happens next
  notes?: string;                // Freeform context (optional)
}
```

### 4.2 Agent Session State (entire spoke file)

```typescript
interface AgentSessionState {
  sessionId: string;             // e.g., "opencode-a3f9b2-7843"
  agentType: string;             // 'opencode' | 'claude' | 'codex' | 'gemini'
  terminalId: string;            // Full terminal ID from renderer
  projectPath: string;           // Working directory
  createdAt: string;             // ISO 8601 session start
  updatedAt: string;             // ISO 8601 last update
  history: AgentCycleState[];    // Latest 3 cycles, [0] = current, [1] = prev, [2] = prev-prev
}
```

```typescript
interface GlobalStateIndex {
```

## 5. File Formats (Exact Markdown)

### 5.1 Spoke File — `agent/state/{sessionId}.md`

```markdown
<!-- AGENT STATE SPOKE — DO NOT EDIT FORMAT -->
<!-- SESSION: opencode-a3f9b2-7843 -->
<!-- AGENT: opencode | TERMINAL: a3f9b2 | PROJECT: /home/clement/deskflow -->

# Agent State — opencode-a3f9b2-7843

> **STATUS:** working | **UPDATED:** 2026-07-25T18:58:00+07:00

---

## CURRENT CYCLE (214)
**ROLE:** Implementing multi-agent state system
**STATUS:** working
**IN FLIGHT:**
- Design state data model
- Write protocol specification
**COMPLETED:**
- Analyzed current state.md flaws
**NEXT ACTION:** Write state.md redesign spec
**NOTES:** (optional freeform)

---

## HISTORY (previous 2 cycles, oldest first)

### Cycle 213 — 2026-07-25T18:45:00+07:00
**ROLE:** Debugging terminal height issue
**STATUS:** completed
**IN FLIGHT:** (none)
**COMPLETED:**
- Fixed terminal height calculation
- Verified toggle/config behavior
**NEXT ACTION:** Start multi-agent state redesign

### Cycle 212 — 2026-07-25T18:30:00+07:00
**ROLE:** Created TERMINAL_CONTEXT_BUNDLE.md
**STATUS:** completed
**IN FLIGHT:** (none)
**COMPLETED:**
- Generated full source code bundle
**NEXT ACTION:** Deliver bundle to user
```

**Format rules:**
1. HTML comments at top for machine parsing (session ID, agent type, terminal, project)
2. `## CURRENT CYCLE (N)` — always present, always the current cycle
3. `## HISTORY` — contains previous 2 cycles, oldest first
4. Each cycle block has identical fields: ROLE, STATUS, IN FLIGHT, COMPLETED, NEXT ACTION
5. IN FLIGHT and COMPLETED are bullet lists (even if empty, write `(none)`)
6. NOTES is optional — omit the line if empty
7. Timestamps are ISO 8601 with timezone offset
8. File is overwritten completely on every cycle — never appended

**Format rules:**
1. Version marker in title: `(v2.0)`
2. `## YOUR SESSION` — personalized section showing this agent's session ID and file path
3. `## ACTIVE AGENTS` — markdown table, one row per active session
4. `## RECENT EVENTS` — chronological list, newest first, max 10 entries
5. `## PROTOCOL` — instructions that every agent reads and follows
6. Hub is regenerated by main process whenever any spoke changes
7. Hub is written atomically (temp file + rename)

## 6. Read/Write Protocol

### 6.1 Agent Startup Ritual (replaces old ritual)

Replace the current `## 1. Startup ritual` in `agent/DEFAULT_SYSTEM_PROMPT.md` with:

```markdown
## 1. Startup ritual (do this BEFORE acting, every session)

These files are force-loaded into your context via `opencode.json` "instructions":
`AGENTS.md`, `MEMORY.md`, `agent/state.md`, `agent/dictionary.md`, `agent/FEATURE_TRACKER.md`,
`agent/context.md`, `agent/PROBLEMS.md`.

### Multi-Agent State v2.0 Protocol

1. **Read the Hub:** Read `agent/state.md` FIRST.
   - See all active agents and their current focus
   - Locate your SESSION_ID in the "YOUR SESSION" section
   - If your session is not listed, you are a new session — proceed to step 3

2. **Identify yourself:**
   - Check environment variable: `DESKFLOW_SESSION_ID`
   - If set, that's your session ID (e.g., `opencode-a3f9b2-7843`)
   - If NOT set, derive it: `{agentType}-{terminalId.slice(0,6)}-{Date.now().toString(36).slice(-4)}`
   - Remember your session ID — you will use it for all state operations

3. **Read your Spoke:** Read `agent/state/{SESSION_ID}.md`
   - Recover your cycle number, role, in-flight work, and history
   - If the file doesn't exist, create it from `agent/state/_template.md`
   - If the file exists but is empty/corrupted, recreate it from template
   - NEVER ask the user for status you can read from your spoke file

4. **Cross-agent awareness (optional):**
   - If you need to coordinate with another agent, read their spoke file directly
   - Example: `agent/state/claude-b7e1c4-5521.md`
   - Only do this when necessary — it costs tokens
```

### 6.2 Agent Cycle-End Ritual (replaces old memory discipline)

Replace the current `## 4. Memory discipline` in `agent/DEFAULT_SYSTEM_PROMPT.md` with:

```markdown
## 4. Memory discipline (anti-amnesia)

At the end of EVERY cycle:

1. **Prepare your state:**
   - Increment cycle number from your spoke file
   - Update role, status, in-flight items, completed items, next action
   - Set timestamp to current time (ISO 8601 with timezone)
   - Move the previous "CURRENT CYCLE" into "HISTORY"

2. **Maintain the history window:**
   - Keep exactly 3 cycles: CURRENT + 2 previous
   - If you have more than 2 in HISTORY, discard the oldest
   - HISTORY is ordered oldest → newest (top to bottom)

3. **Write your spoke:**
   - Overwrite `agent/state/{SESSION_ID}.md` completely
   - Use the exact format from `agent/state/_template.md`
   - Include the HTML comments at the top for machine parsing
   - Write atomically if possible (write to temp file, then rename)

4. **NEVER do these things:**
   - NEVER write to `agent/state.md` (the Hub) — it is read-only for agents
   - NEVER write to another agent's spoke file
   - NEVER append to your spoke — always overwrite completely
   - NEVER keep more than 3 cycles (wastes tokens)
   - NEVER keep fewer than 3 cycles (loses history)
```

## 7. Conflict Resolution

### 7.1 The Core Guarantee

Since each agent writes to its **OWN** spoke file, **inter-agent write conflicts are impossible by design.**

The only shared file is the Hub (`agent/state.md`), which is:
- **Read-only for all agents** — agents never write to it
- **Written only by the main process** — a single writer eliminates conflicts
- **Written atomically** — temp file + `fs.rename` guarantees no partial writes

### 7.2 Atomic Write Pattern (Main Process)

```typescript
async function writeFileAtomic(filePath: string, content: string): Promise<void> {
  const tempPath = `${filePath}.tmp.${Date.now()}`;
  await fs.writeFile(tempPath, content, 'utf-8');
  await fs.rename(tempPath, filePath);  // Atomic on all POSIX + Windows
}
```

### 7.3 Crash Recovery

| Scenario | Recovery |
|----------|----------|
| Main process crashes during Hub write | Temp file left behind; next startup cleans it up and regenerates Hub from spokes |
| Agent crashes during spoke write | Spoke may be partially written; next cycle the agent reads it, detects corruption, and recreates from template |
| Two agents with same session ID | Second agent overwrites first's spoke — prevented by unique entropy in session ID generation |
| Disk full during write | Atomic write prevents partial Hub; spoke write fails, agent logs error and retries next cycle |

## 8. Cross-Agent Awareness Levels

Agents can choose how much cross-agent context to load:

| Level | What to Read | Token Cost | Use Case |
|-------|-------------|------------|----------|
| **L1: Hub only** | `agent/state.md` | ~200 tokens | Quick awareness: who's active, what are they doing |
| **L2: Spoke peek** | Hub + 1 specific spoke | ~500 tokens | Need details on one other agent's work |
| **L3: Full sync** | Hub + all spokes | ~1200-1500 tokens | Complex coordination, dependency checking, handoffs |

**Default:** All agents load L1 (Hub is in `opencode.json` instructions).  
**Escalation:** Agent reads specific spoke files only when needed.  
**Token budget:** Even with 4 agents at L3, total state context is ~1500 tokens — well within limits.

```typescript
async function migrateToMultiAgentState(): Promise<void> {
  // Already migrated?
  try {
    await fs.access(STATE_DIR);
    return;  // Directory exists = already migrated
  } catch { /* continue */ }

  // Create state directory
  await fs.mkdir(STATE_DIR, { recursive: true });

  // Parse old state.md
  let oldContent = '';
  let oldCycle = 0;
  let oldRole = 'Unknown';
  let oldAgentType = 'unknown';

  try {
    oldContent = await fs.readFile(OLD_STATE_PATH, 'utf-8');
    const cycleMatch = oldContent.match(/CYCLE:\s*(\d+)/);
    const roleMatch = oldContent.match(/ROLE:\s*(.+)/);
    const agentMatch = oldContent.match(/AGENT:\s*(\w+)/i);
    oldCycle = cycleMatch ? parseInt(cycleMatch[1]) : 0;
    oldRole = roleMatch ? roleMatch[1].trim() : 'Unknown';
    oldAgentType = agentMatch ? agentMatch[1].toLowerCase() : 'unknown';
  } catch {
    oldContent = '# DeskFlow — Current State\nCYCLE: 0\nROLE: Initializing\n';
  }

  // Create legacy spoke
  const legacySessionId = `${oldAgentType}-legacy-${Date.now().toString(36).slice(-4)}`;
  const legacySpoke = generateSpokeFromLegacy(legacySessionId, oldAgentType, oldCycle, oldRole, oldContent);
  await fs.writeFile(path.join(STATE_DIR, `${legacySessionId}.md`), legacySpoke, 'utf-8');

  // Write template
  await fs.writeFile(TEMPLATE_PATH, SPOKE_TEMPLATE, 'utf-8');

  // Generate initial Hub
  const hubContent = generateHub([{
    sessionId: legacySessionId,
    agentType: oldAgentType,
    terminalId: 'legacy',
    currentCycle: oldCycle,
    status: 'unknown',
    currentFocus: oldRole,
    lastSeen: new Date().toISOString()
  }]);

  // Backup old state
  await fs.copyFile(OLD_STATE_PATH, `${OLD_STATE_PATH}.pre-v2`);

  // Replace with Hub
  await writeFileAtomic(OLD_STATE_PATH, hubContent);
}
```

### File 3: `src/main/stateCoordinator.ts` (NEW)

```typescript
import { promises as fs, watch, FSWatcher } from 'fs';
import path from 'path';

interface SpokeSummary {
  sessionId: string;
  agentType: string;
  terminalId: string;
  currentCycle: number;
  status: string;
  currentFocus: string;
  lastSeen: string;
  updatedAt: string;
}

export class StateCoordinator {
  private stateDir: string;
  private hubPath: string;
  private watcher: FSWatcher | null = null;
  private debounceTimer: NodeJS.Timeout | null = null;

  constructor(agentDir: string = 'agent') {
    this.stateDir = path.join(agentDir, 'state');
    this.hubPath = path.join(agentDir, 'state.md');
  }

  async initialize(): Promise<void> {
    await fs.mkdir(this.stateDir, { recursive: true });
    await this.regenerateHub();
    this.startWatching();
  }

  private startWatching(): void {
    this.watcher = watch(this.stateDir, (eventType, filename) => {
      if (!filename || filename.startsWith('_') || !filename.endsWith('.md')) return;
      // Debounce: wait 500ms after last change
      if (this.debounceTimer) clearTimeout(this.debounceTimer);
      this.debounceTimer = setTimeout(() => this.regenerateHub(), 500);
    });
  }

  async regenerateHub(): Promise<void> {
    try {
      const files = await fs.readdir(this.stateDir);
      const spokeFiles = files.filter(f => f.endsWith('.md') && !f.startsWith('_'));

      const summaries: SpokeSummary[] = [];
      for (const file of spokeFiles) {
        try {
          const content = await fs.readFile(path.join(this.stateDir, file), 'utf-8');
          const summary = this.parseSpoke(content);
          if (summary) summaries.push(summary);
        } catch (e) {
          console.error(`Failed to parse spoke ${file}:`, e);
        }
      }

      const hubContent = this.generateHubContent(summaries);
      await this.writeFileAtomic(this.hubPath, hubContent);
    } catch (e) {
      console.error('Failed to regenerate hub:', e);
    }
  }

  private parseSpoke(content: string): SpokeSummary | null {
    // Extract from HTML comments
    const sessionMatch = content.match(/<!-- SESSION: (.+) -->/);
    const agentMatch = content.match(/<!-- AGENT: (.+?) \|/);
    const terminalMatch = content.match(/<!-- AGENT: .+ \| TERMINAL: (.+?) \|/);

    // Extract from CURRENT CYCLE section
    const cycleMatch = content.match(/## CURRENT CYCLE \((\d+)\)/);
    const statusMatch = content.match(/\*\*STATUS:\*\* (.+)/);
    const roleMatch = content.match(/\*\*ROLE:\*\* (.+)/);
    const updatedMatch = content.match(/\*\*UPDATED:\*\* (.+)/);

    if (!sessionMatch || !cycleMatch) return null;

    const updatedAt = updatedMatch ? updatedMatch[1] : new Date().toISOString();
    const date = new Date(updatedAt);
    const lastSeen = isNaN(date.getTime()) 
      ? 'unknown' 
      : date.toLocaleTimeString('en-US', { hour: '2-digit', minute: '2-digit', hour12: false });

    return {
      sessionId: sessionMatch[1].trim(),
      agentType: agentMatch ? agentMatch[1].trim() : 'unknown',
      terminalId: terminalMatch ? terminalMatch[1].trim() : 'unknown',
      currentCycle: parseInt(cycleMatch[1]),
      status: statusMatch ? statusMatch[1].trim().toLowerCase() : 'unknown',
      currentFocus: roleMatch ? roleMatch[1].trim() : 'Unknown',
      lastSeen,
      updatedAt
    };
  }

  private generateHubContent(summaries: SpokeSummary[]): string {
    const now = new Date().toISOString();
    const timeStr = new Date().toLocaleTimeString('en-US', { 
      hour: '2-digit', minute: '2-digit', hour12: false 
    });

    const rows = summaries.map(s => 
      `| ${s.agentType} | ${s.sessionId} | ${s.currentCycle} | ${s.status} | ${s.currentFocus} | ${s.lastSeen} |`
    ).join('\n');

    return `# DeskFlow — Multi-Agent State Hub  (v2.0)

> **SYSTEM:** Multi-agent state v2.0 | **UPDATED:** ${now} | **GENERATED BY:** main-process

---

## YOUR SESSION
**ID:** \`{YOUR_SESSION_ID}\`
**FILE:** \`agent/state/{YOUR_SESSION_ID}.md\`
> Read YOUR file for full history. Write to it at cycle end. NEVER edit this hub.

---

## ACTIVE AGENTS (${summaries.length})

| AGENT | SESSION | CYCLE | STATUS | FOCUS | LAST SEEN |
|-------|---------|-------|--------|-------|-----------|
${rows}

---

## RECENT EVENTS (last 10)
${summaries.map(s => `- \`[${s.lastSeen}]\` ${s.sessionId} → ${s.status}: ${s.currentFocus}`).slice(0, 10).join('\n')}

---

## PROTOCOL — READ CAREFULLY
1. **READ:** Your spoke file (\`agent/state/{YOUR_SESSION}.md\`) for full history
2. **WRITE:** Overwrite your spoke file at cycle end (keep latest 3 cycles)
3. **NEVER** write to this hub file — it is auto-generated by the main process
4. **CROSS-AGENT:** Read other spoke files if you need details on their work
5. **FORMAT:** Follow \`agent/state/_template.md\` exactly
6. **SESSION ID:** Check \`DESKFLOW_SESSION_ID\` env var, or derive from \`{agentType}-{terminalId.slice(0,6)}-{entropy}\`
`;
  }

  private async writeFileAtomic(filePath: string, content: string): Promise<void> {
    const tempPath = `${filePath}.tmp.${Date.now()}`;
    await fs.writeFile(tempPath, content, 'utf-8');
    await fs.rename(tempPath, filePath);
  }

  dispose(): void {
    if (this.watcher) {
      this.watcher.close();
      this.watcher = null;
    }
    if (this.debounceTimer) {
      clearTimeout(this.debounceTimer);
      this.debounceTimer = null;
    }
  }
}
```

## 12. Edge Cases & Handling

| Edge Case | Detection | Handling |
|-----------|-----------|----------|
| **Agent crash mid-cycle** | Spoke has last completed cycle; no "in-flight" marker | Next startup: agent reads spoke, sees last completed cycle, asks user if task was finished |
| **Duplicate session IDs** | Two files with same session ID prefix | Main process logs warning; both agents continue (last write wins for that spoke) |
| **Hub generation fails** | Hub timestamp is stale (>5 min old) | Agents detect stale hub from timestamp; still functional via own spoke files |
| **Spoke file corrupted** | Parse errors in HTML comments or CURRENT CYCLE | Agent recreates from template, preserves what it can parse |
| **Disk full** | Write throws ENOSPC | Atomic write prevents partial files; agent retries next cycle; main process logs error |
| **Agent type unknown** | No DESKFLOW_AGENT_TYPE env var | Fallback to 'unknown' in session ID; hub shows 'unknown' agent type |
| **Legacy state.md exists** | No `agent/state/` directory | Migration runs on startup; preserves backup |
| **Template missing** | `agent/state/_template.md` not found | Main process recreates template on startup |
| **History overflow** | Agent keeps >3 cycles | Agent protocol enforces exactly 3; main process can validate and trim |
| **Very long role/focus** | >100 chars | Truncated in Hub table; full text preserved in spoke |
