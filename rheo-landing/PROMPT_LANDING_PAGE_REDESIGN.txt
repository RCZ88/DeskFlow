## ── THE DESIGN RULES (non-negotiable, from handoff doc) ──

1. Dark mode only. No new colors outside existing tokens.
2. Every animation uses GSAP ScrollTrigger or page-load stagger tween, with
   the registered easeInOutCubic. No default ease.
3. Respect prefers-reduced-motion — new elements need a static end-state in
   that branch too.
4. Real alt text per mascot (use the subsystem label) — not alt="".
5. Single motif everywhere: thread / stitching / patches. If it doesn't read
   as "made of thread," it's wrong even if it looks good on its own.
6. One visual language per section type — don't add a second card style, a
   second icon style, or a second color for "new feature" sections.
7. The SVG loom animation is GOOD — don't replace it. New elements coexist
   with it (hero PNGs sit on top as small accents; module store is a separate
   section that never had SVG weave to begin with).
